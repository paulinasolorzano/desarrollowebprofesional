Sistema Administrativo Web
Construcción progresiva de un sistema real de gestión de personas, usuarios, proyectos y tareas, aplicando desarrollo web moderno y seguridad en cada capa de la aplicación.
Materia 1
Desarrollo Web Profesional
Construcción de APIs REST con Node.js y Express, interfaces reactivas con React y Vite, comunicación cliente-servidor, manejo de estado y arquitectura MVC aplicada a un sistema real.
Materia 2
Seguridad en el Desarrollo de Aplicaciones
Autenticación con JWT, cifrado de contraseñas con bcrypt, control de acceso por roles y permisos, protección contra vulnerabilidades web comunes y buenas prácticas de seguridad en cada capa.
¿Qué es este proyecto?

Este proyecto integra ambas materias en un único sistema administrativo construido de forma progresiva a lo largo del cuatrimestre. Cada práctica añade un componente nuevo sobre lo anterior: primero la base de datos, luego el servidor, después la interfaz, y finalmente la seguridad completa con autenticación, autorización y permisos granulares.

Al finalizar el curso tendrás un sistema funcional, seguro y con arquitectura profesional que podrás incluir en tu portafolio de proyectos.

Módulos del sistema
Módulo 1
Personas
Registro de cualquier individuo de la organización, con o sin acceso al sistema.
Módulo 2
Usuarios
Cuentas de acceso vinculadas a personas. Control de roles: admin, usuario, invitado.
Módulo 3
Proyectos
Gestión de proyectos con responsable, fechas, prioridad y estado de avance.
Módulo 4
Tareas
Tareas vinculadas a proyectos y responsables. Con prioridad, estado y fechas de entrega.
Temas de Desarrollo Web Profesional
  • Diseño de bases de datos relacionales con MySQL
  • Creación de APIs REST con Node.js y Express
  • Patrón de arquitectura MVC (Modelo-Vista-Controlador)
  • Construcción de interfaces con React y Vite
  • Enrutamiento con React Router DOM
  • Manejo de estado global con Context API
  • Consumo de APIs desde el frontend con axios
  • Operaciones CRUD completas (Create, Read, Update, Delete)
  • Relaciones entre tablas y consultas JOIN en MySQL
Temas de Seguridad en el Desarrollo
  • Autenticación con JSON Web Tokens (JWT)
  • Cifrado de contraseñas con bcrypt
  • Protección de rutas en el frontend (PrivateRoute)
  • Middleware de autenticación en Express
  • Control de acceso basado en roles (RBAC)
  • Sistema de permisos granulares por recurso y acción
  • Uso seguro de variables de entorno (.env)
  • Protección con CORS, helmet y rate limiting
  • Buenas prácticas contra vulnerabilidades web comunes
